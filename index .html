RDP / Remote Access

Connection steps, troubleshooting, enumeration, and security checks for RDP.

Connection steps
1
Confirm port open: nmap -sV -p3389 <target>
2
Check NLA requirement: nmap --script rdp-ntlm-info -p3389 <target>
3
Connect (Linux): xfreerdp /v:<target> /u:<user> /p:<pass>
4
Connect (alt): rdesktop -u <user> -p <pass> <target>
5
Windows native: mstsc /v:<target>
Troubleshooting
CredSSP errorAdd /sec:nla or downgrade with /sec:rdp
Black screenTry /gfx:off in xfreerdp
Cert warningAdd /cert-ignore
Slow connectionAdd /compression /bpp:8
Enumeration before connecting
rdp-sec-checkChecks encryption level and NLA
nmap --script rdp-vuln-ms12-020Checks classic RDP DoS CVE
hydra rdp bruteforcehydra -l user -P list.txt rdp://target
Security checks
NLA disabledAllows pre-auth attack surface (BlueKeep-class)
Weak/reused credsMost common real-world RDP compromise vector
Old Windows versionCheck against BlueKeep (CVE-2019-0708), DejaBlue
