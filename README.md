### About

This project is a personal security reference workspace that collects useful tools, commands, scripts, and learning resources in one place.

## Usage
> Open `index.html` in a browser. No install, no build step.

1. Open the reference page
2. Search for a tool or command
3. Follow examples and documentation
4. Practice in legal environments/labs
